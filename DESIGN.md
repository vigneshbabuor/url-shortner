# LinkPulse Design System

Minimal dark-mode dashboard. OpenDesign-style DESIGN.md so any future prototype/codegen stays on-brand.

## Palette
- bg: #0d1117
- surface: #161b22
- border: #30363d
- text: #e6edf3
- text-muted: #8b949e
- accent: #58a6ff (primary actions, links)
- accent-hover: #79b8ff
- success: #3fb950
- danger: #f85149

## Typography
- Font: system-ui stack ("Segoe UI", Roboto, Helvetica, Arial, sans-serif)
- Page title: 24px / 600
- Body: 14px / 400
- Muted meta: 12px

## Spacing & shape
- Radius: 8px (cards, inputs, buttons)
- Card padding: 20px
- Gap scale: 4 / 8 / 12 / 16 / 24
- Max content width: 860px, centered

## Components
- Input: dark surface bg, 1px border, focus ring accent
- Button: accent bg, #0d1117 text, 600 weight, hover accent-hover
- Table: header text-muted uppercase 12px, rows separated by border, hover row bg surface
- Badge (click count): pill, surface bg, muted text
- Sparkbar (7-day): flex bars, accent, height scaled to max
